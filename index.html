OVERVIEW

이게 무엇인가요?

제 3회 오량모의국회 WebApp은 약 150명의 의원과 운영진이 실시간으로 소통하고, 안건에 투표하며 의회를 경험하는 온라인 플랫폼입니다.

  • 🗳️
    실시간 투표 — 안건에 찬성·반대·기권으로 의사 표명
  • 💬
    채팅 — 전체 공지방 · 정당 채팅방 · 일반 채팅방
  • 📢
    흐르는 공지 배너 — 운영진 공지가 상단에 실시간 전파
  • 📋
    프로그램 안내 — 일정·상임위·정당 정보 한눈에 확인
  • 🆘
    관리자 호출 — 문제 발생 시 즉시 운영진에게 연결

VOTE

안건 투표

  • 🟢
    투표 진행 중 — 초록 펄스 배지. 지금 바로 투표 가능.
  • ⚫
    대기 중 — 운영진이 열기 전까지 투표 불가.
  • ✔
    좌측 목록에서 안건 선택 → 우측에서 찬성 / 반대 / 기권 클릭.
⚠️
결과는 비공개!
투표 완료 후 내 의사("찬성했습니다")만 보입니다. 전체 찬반 비율은 운영진이 공개할 때만 팝업으로 표시됩니다.
💡 투표는 로그인 필수. 한 안건당 한 번만 투표 가능하며 변경 불가.
🏆
운영진이 결과를 공개하면 전체 화면에 투표 결과 팝업이 표시됩니다. 비로그인 게스트도 볼 수 있습니다.
CHAT

채팅방의 종류

📢
전체 공지방
모든 사용자 자동 가입. 운영진(Admin)만 메시지 전송 가능. 일반 의원은 읽기 전용.
🏳️
정당 채팅방
소속 정당(진보/보수/중도)에 자동 가입. 같은 당 의원끼리만 소통 가능.
💬
일반 채팅방
직접 방 생성 또는 초대받아 참여. 자유로운 소통 공간.
💡 무소속은 정당 채팅방 없음. 전체 공지방 + 일반 채팅방 사용 가능.

채팅 — 대화하기

  • 📎
    파일 첨부 — 이미지·PDF·TXT (10MB↓). 클립 버튼 또는 드래그&드롭.
  • 📌
    공지 핀 — 방장이 설정한 공지가 메시지 목록 상단에 고정. 클릭 시 전체 내용 확인.
  • 🖼️
    PIP 모드 — 채팅창을 작은 창으로 분리해 다른 페이지를 보면서도 동시에 채팅 가능!
⌨️ / 명령어 (방장 전용)
/kick 이름 — 방에서 강제 퇴장
/announcement 내용 — 방 공지 설정
/promote 이름 — 방장 권한 양도
/leave — 방에서 나가기
채팅창에 / 입력 시 명령어 목록 팝업 자동 표시 (Tab으로 완성)
